🛒 PyShop

PyShop is a Django-based fruit shop project designed to provide a simple foundation for building a modern e-commerce platform.

The project currently focuses on product management and serves as the foundation for future features such as shopping carts, user accounts, orders, payments, and a mobile application.

🚀 Features
Product management
Product pricing and stock tracking
Product images
Special offers and discounts
Django administration
SQLite database
Reusable HTML templates
Scalable Django structure

▶️ Getting Started

Clone the repository, install Django, and run the development server:

git clone https://github.com/GloriousDev12/PyShop.com.git
cd PyShop.com
pip install django
python manage.py migrate
python manage.py runserver

Then open:

http://127.0.0.1:8000/
